# Космический синтез (Cosmic Merge)

Физическая головоломка для [Яндекс Игр](https://yandex.ru/games/) на Phaser 3: бросайте планеты в банку, две одинаковые сливаются в следующую, большую, — от космической пыли до Солнца.

## Возможности

- Phaser 3.80, `Phaser.Scale.RESIZE`, физика Matter.js, вся графика и звук генерируются кодом (без внешних ассетов).
- Яндекс SDK: инициализация, `LoadingAPI.ready`, `GameplayAPI`, облачные сохранения с запасным `localStorage`.
- Реклама: межстраничная не чаще раза в 2 минуты и только между раундами; rewarded — воскрешение, x2 монеты, бесплатные монеты (награда только в `onRewarded`). На время рекламы игра ставится на паузу, звук выключается.
- Внутриигровые покупки: пакеты монет и «Без рекламы», консумирование, защита от двойного начисления, цена и иконка валюты берутся из SDK.
- RU/EN, бустеры «Встряхнуть» и «Чистка», комбо, уровни.

## Структура

```
index.html            точка входа (подключает SDK Яндекс Игр и Phaser)
src/main.js           создание игры
src/config.js         настройки, планеты, тексты RU/EN
src/yandexSDK.js      обёртка над SDK: сохранения, реклама, покупки
src/audio.js          синтез звуков и музыки
src/ui.js             процедурные текстуры и UI-компоненты
src/scenes/           Boot, Menu, Play, Shop
build.sh              сборка dist/ и cosmic-merge.zip для консоли Яндекс Игр
store/                материалы для каталога: иконка, обложка, скриншоты, видео, иконки покупок
```

## Запуск локально

```sh
python3 -m http.server 8080
# открыть http://localhost:8080/?debug
```

Вне Яндекса игра работает в режиме `dev`: реклама и покупки эмулируются. С `?debug` в консоли доступен `window.__game`.

## Сборка для Яндекс Игр

```sh
sh build.sh   # создаёт cosmic-merge.zip с локальным phaser.min.js
```

Архив загружается во вкладке «Черновик» консоли разработчика.
